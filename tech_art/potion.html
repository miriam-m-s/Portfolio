SH_WaterShader: Technical Potion 🧪

A Unity URP shader simulating reactive volumetric liquid. Driven by HLSL+ShaderGraph math and C# inertia physics forthe sloshing effect.

View C# Code

Quick Details

Unity URP HLSL C#

Technical Overview 🛠️

This project focuses on simulating fluid physics within a container without 3D fluid particles. By using Object-Space calculations, the shader determines the liquid's tilt based on the bottle's velocity.

Core Features

Dynamic Fill: Height clipping via _WaterQuantity.
Reactive Slosh: Rotation driven by C# inertia.
Procedural Bubbles: Time-animated textures.
Foam Edge: Border threshold detection.
Fresnel: Camera-angle dependent edge glow.
Double Sided: Interior rendering for glass.

Parameter Demonstration 🎥

Dynamic preview of runtime changes affecting fill, waves, and color response.

Material Properties 🎛️

Fully exposed parameters for real-time art direction:

  • Fill Level: Precise control over liquid volume.
  • Wave Intensity: Adjustable sloshing amplitude.
  • Bubble Velocity: Speed of procedural particle rise.
  • Shaking Color: Dynamic color shift during movement.
  • Foam Threshold: Thickness of the surface contact foam.
  • Fresnel Color: Edge glow tint and intensity.
